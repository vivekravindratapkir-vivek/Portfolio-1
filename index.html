☀️ hardware project
Arduino IoT C / C++

Automatic Solar Tracker

Four LDR sensors in a voltage-divider arrangement detect the sun's exact position; two servo motors then reorient the panel to maximise light capture — all in a tight feedback loop running on an Arduino. Went through three prototypes before the loop was stable enough for continuous outdoor use. Designed using design-thinking methodology, balancing cost, durability, and real-world performance.
